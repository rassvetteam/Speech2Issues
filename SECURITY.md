# Security policy

Репозиторий приватный. Не публикуйте API-токены, записи, файлы `settings.json`, `secrets.bin` или дампы базы истории.

Для сообщения об уязвимости откройте приватный security advisory в GitHub либо свяжитесь с владельцем организации `rassvetteam`. Не создавайте публичный issue с деталями до согласования исправления.
